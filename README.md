# Dynamics-instructies

Interactieve, klikbare instructies voor accountmanagers in Dynamics 365 Sales: zeven onderwerpen,
elk met een toets van 5 vragen, badges en een scoreboard. Alle gegevens in de instructies zijn verzonnen.

**Website:** https://bobskillstown.github.io/dynamics-instructies-site/

## Scoreboard bijwerken

Collega's sturen hun resultaatcode (startpagina, blok *Mijn resultaatcode*) naar de beheerder.

1. Open `beheer.html` op de website en plak de codes, één per regel.
2. Klik op **Verwerken** en daarna op **Download scores.json**.
3. Upload het bestand hier via **Add file → Upload files** en klik op **Commit changes**.

Na ongeveer een minuut staat het nieuwe scoreboard online.

## Bestanden

De bestanden worden samengesteld vanuit de (privé) bronrepository met `instructie/bouw-site.py`.
Pas ze hier niet met de hand aan, behalve `scores.json`.
